# 🚀 Быстрый старт SpeedDash Pro

## Windows

1. **Откройте PowerShell/CMD** в папке проекта:
```bash
cd "c:\Users\Admin\OneDrive\Desktop\проект -сайт"
```

2. **Установите зависимости**:
```bash
npm install
```

3. **Запустите приложение**:
```bash
npm start
```

Для web-версии с API платежей:
```bash
npm run web
```

Или просто **дважды кликните на `run.bat`**

---

## macOS / Linux

1. **Откройте терминал** в папке проекта:
```bash
cd "~/Desktop/проект -сайт"
```

2. **Дайте права на выполнение скрипту**:
```bash
chmod +x run.sh
```

3. **Запустите приложение**:
```bash
./run.sh
```

Или вручную:
```bash
npm install
npm start
```

---

## 🎯 Что дальше?

### Для разработки
- Меняйте код в `index.html`, `speedTest.js`
- Приложение перезагружается автоматически

### Для сборки приложения

**Windows:**
```bash
npm run build:win
```
Установщик будет в папке `dist/` (файл `.exe`)

**macOS:**
```bash
npm run build:mac
```
Установщик будет в папке `dist/` (файлы `.dmg` и `.zip`)

**Linux:**
```bash
npm run build:linux
```
Установщик будет в папке `dist/` (файлы `.AppImage` и `.deb`)

## 💳 Реальные платежи

1. Создайте `.env` на основе `.env.example`
2. Заполните `STRIPE_SECRET_KEY`, `STRIPE_PUBLISHABLE_KEY`
3. Укажите `APP_BASE_URL` и `ALLOWED_ORIGINS` вашим доменом
4. Добавьте ссылки для `PAYMENT_LINK_SBP`, `PAYMENT_LINK_MIR`, `PAYMENT_LINK_CRYPTO`
5. Запустите `npm run web`

---

## 🌐 Деплой в интернет (Render)

1. Загрузите проект в GitHub
2. Создайте Web Service в Render
3. Render автоматически подхватит `render.yaml`
4. Добавьте переменные из `.env.example` в Render Environment
5. После деплоя откройте `https://<your-domain>/health`

## 🆘 Помощь

Если возникли проблемы:

1. **Ошибка "npm not found"**:
   - Установите Node.js
   - Перезагрузитесь

2. **Ошибка при запуске Electron**:
   - Удалите папку `node_modules`
   - Удалите файл `package-lock.json`
   - Запустите `npm install` заново

3. **Хотите менять код**:
   - Меняйте `index.html`, `speedTest.js`
   - При разработке используйте `npm start`
   - DevTools отключены, используйте `console.log()` для отладки
