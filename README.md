# SpeedDash Pro - Приложение и Веб-сайт

## 📦 Структура проекта

```
js/
```

## 🚀 Установка

### Требования
- Node.js 14+ с npm

### Шаги установки

1. **Установите зависимости**:
```bash
cd "c:\Users\Admin\OneDrive\Desktop\js"
npm install
```

2. **Запустите приложение**:
```bash
npm start
```

3. **Создайте установщик**:
```bash
# Для Windows
npm run build:win

# Для Mac
npm run build:mac

# Для Linux
npm run build:linux
```

## 🌐 Размещение в интернете

1. Скопируйте `.env.example` в `.env` и заполните платежные ключи/ссылки.
2. Укажите домен в `APP_BASE_URL` и `ALLOWED_ORIGINS` (например, `https://your-domain.com`).
3. Проверьте локально:
   ```bash
   npm install
   npm run web
   ```
4. Для Render можно использовать готовый `render.yaml` (Build: `npm install`, Start: `npm run web`).
5. Добавьте переменные окружения из `.env.example` в настройках Render.
6. После деплоя откройте `/health` для проверки, что сервер работает.
7. Подробный чек-лист: `DEPLOY_RENDER.md`.

## 📝 Примечания

- Данные истории хранятся только в локальном хранилище браузера
- При очистке localStorage все данные удалятся
- Тесты скорости требуют интернета
- Точность зависит от качества соединения
